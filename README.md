# VID2GIF LITE – Lightweight Offline Video to GIF Converter v1.0.0

VID2GIF LITE v1.0.0 is a lightweight desktop application designed to quickly convert video files into optimized GIFs in a simple, fast, and fully offline workflow. It supports batch processing, drag-and-drop input, and flexible output settings using FFmpeg.

Built with Python, Tkinter, ttkbootstrap, and tkinterdnd2, VID2GIF LITE is designed for creators, developers, editors, and anyone who needs a reliable offline tool to convert videos into GIFs without complexity.

------------------------------------------------------------
USAGE GUIDE
------------------------------------------------------------

1. Add Video Files  
Drag and drop video files into the application or click "Select Videos".

2. Choose Output Folder  
Select where the generated GIF files will be saved.

3. Adjust Settings  
Set FPS, resolution, and filename prefix.

4. Start Conversion  
Click "Start" to begin processing.

5. Monitor Progress  
View real-time logs and progress bar updates.

6. Access Output  
Automatically open output folder after completion (optional).

------------------------------------------------------------
CONVERSION WORKFLOW
------------------------------------------------------------

1. User selects one or more video files  
2. Application filters supported formats  
3. Output folder is selected  
4. FFmpeg generates color palette for each video  
5. FFmpeg converts video frames into optimized GIF  
6. Files are saved with custom prefix  
7. Progress bar updates in real time  
8. Logs show processing status  
9. Completion message is displayed
